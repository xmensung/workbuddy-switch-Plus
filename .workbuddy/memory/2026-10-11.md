## WorkBuddy 多账号积分到期监控 — 开源调研

- 需求：为 3 个 WorkBuddy 账号做积分过期监控，先查 GitHub 有无现成开源项目。
- 结论：已有多个成熟方案，无需从零自研。
- 最贴合：`changexbc/workbuddy-switch`（MIT，Rust + Tauri，~1.2k★）
  - 自动查询每个账号积分剩余量与到期时间；7 天内到期高亮，按紧迫程度排序并标注「建议优先使用」
  - 另含账号切换、会话复制、积分统计、Token 统计、CodeBuddy CLI 自动轮换
  - Win/mac/Linux 安装包 + `npm i -g workbuddy-switch` 的 webui 版
- 备选：
  - 青竹 Buddy `qingzhu-ai-public/workbuddy-account-manager-public`：发行仓（无源码），托盘常驻 + 自动刷新积分/到期 + 自动签到，v1.5.0
  - `smart-open/TraeWorkAssistant`（AI Work 助手，MIT，Tauri2+React+Rust，~253★）：六应用多账号，积分看板含到期日历/趋势，功能最全但偏重
  - `babygoton/WorkDaddy`、`L0NE-6/WorkBuddy-Daily`（签到脚本）、`AoGuSun/workbuddy2api`（网关，含「快过期分桶」+ credit.sh 积分日报）
- 通用参考：`Simmons-jg/aigc-credit-radar`（多平台 AIGC 积分过期雷达，WorkBuddy 未内置连接器，需手动录入；架构可借鉴）
- 领域知识：WorkBuddy 积分按月发放、当月有效不结转；系统按「最早到期优先」扣减（个人版/加量包/赠送积分）。官方文档 codebuddy.cn/docs/workbuddy/Credits
- 风险：这些工具需读取本机登录态（auth/.info）调用官方接口，属非官方工具，使用需自担账号/条款风险。
- 用户追问：能否把「青竹 Buddy 的自动签到」与「workbuddy-switch 的到期监控提醒」结合。
  - 可行性：两者各自持有全部账号凭证、独立调官方接口，不共享数据，可并列共存。
  - 冲突点：① 勿同时用两者的「切换登录态」（一机一客户端只有一份当前登录态）；② 勿让两者都开高频自动刷新（官方接口密集访问触发 HTTP 418 风控，青竹下限锁 30 分钟）→ 建议只让青竹自动刷新，workbuddy-switch 手动刷新看「7 天到期高亮」。
  - 二合一现成方案：`smart-open/TraeWorkAssistant`（AI Work 助手）同一 App 内同时有「积分看板（含到期日历）」+「一键/定时签到」；代价是偏重、覆盖六应用、作者警告风控封号风险。
  - 待定：用户选择「并列安装两 App」/「改用 AI Work 助手」/「自建整合小工具」。
- 【更新】用户决定**不要签到功能**，需求收窄为「只监控 3 个账号积分到期」。
  - 收窄后最优解：单用 `changexbc/workbuddy-switch` 的「积分到期查询」（纯只读：查余额+到期，7 天内高亮、按紧迫度排序、标「建议优先使用」），已足够。
  - 待补差距：该工具的到期提醒是**应用内**高亮，非系统级推送；若要「未打开也提醒」需常驻或自建极简提醒版。
- 【决定】用户选定：**单用 changexbc/workbuddy-switch**，只要到期监控、不要签到。
  - 最新版 v0.1.60（2026-10-09）；Windows 安装包 `workbuddy-switch_0.1.60_x64-setup.exe`（8.86 MB），sha256 `71bdc5f0c3414c8ac0a69cd072af5e2d57534e693ddbd73bfd3fa492642c3fed`。
  - 只读演示站（可先看界面）：https://changexbc.github.io/workbuddy-switch/ ；npm 网页版：`npm i -g workbuddy-switch`。
  - 当前环境外网下载被沙箱代理拦截（CONNECT tunnel 502），未能代为下载安装包，已给用户直链让其手动下载。
