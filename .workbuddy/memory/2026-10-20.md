## v0.1.70：环形图三档（72 小时红 / 7 天橙）

### 用户要求

1. 72 小时内到期的积分用**红色**显示，并标记**最近的到期时间**；
2. 7 天内到期（= 168 小时）用**橙色**显示；
3. 更新版本号。

### 实现

**`src/index.css`**：新增 `--credit-soon`（橙），浅深主题各一套。
- 浅色 `oklch(0.685 0.172 46)` ≈ **#ED712B**；深色 `oklch(0.775 0.155 55)`。
- **刻意避开** `oklch(0.735 0.137 70)`（≈ #E09839，用户否过的浊琥珀），改用高彩度 hue 46 真橙。
- 同时把浅色 `--credit-expiring` 从 `oklch(0.622 0.208 25)`（#EA3E40 珊瑚红）**调深**
  到 `oklch(0.585 0.215 22)`（#DF273C 绯红）——原来那个红跟橙在 15px 细环上几乎分不出来，
  顺带把红字白底对比度提了一档。

**`src/pages/CreditFloatPage.tsx`**
- `Tone` 改为 `"urgent" | "soon" | "later"`；`TONE_ORDER` 按紧急度排（红从 12 点开始）。
- 常量：`URGENT_HOURS = 72` / `SOON_HOURS = 168`，由它们推出 `URGENT_DAYS = 3` / `SOON_DAYS = 7`。
  **判定仍按整天**（`daysUntil`）——官方 `expireAt` 是到期日当天 00:00，真实数据上
  「days ≤ 3」≡「72 小时内」、「days ≤ 7」≡「168 小时内」，二者等价，且不会一屏两种口径。
- `AccountSummary` 字段改为 `urgentAmount` / `soonAmount`（后者**只含 72h~7d**，不含红档）
  + `urgent[]`（逐笔）/ `soonBuckets[]`（按到期日合并，仅橙档）。
- 缺 `resources` 的兜底分支：`expiringSoonRemaining` 现在归**橙段**（原先一律算绿），
  剩余部分给绿段。
- `SoonNotice` 重写：红块（合计 + 逐笔列表，或单笔时一行「MM-DD 到期 · N 天后」）
  + 橙块（合计 + 最近到期日 + 「另有 N 个到期日」），两档可同时出现；都为空才显示灰字。
  逐笔列表**只在 >1 笔时**出现，单笔时不与「最近到期」行重复。
- 图例三项（72 小时内到期 / 7 天内到期 / 其余可用），每项带 `title` 说明小时数。
- 新增 `Clock` 图标用于橙档（红档继续 `AlertTriangle`）。
